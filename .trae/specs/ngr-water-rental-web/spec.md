# 尼日利亚水机租赁平台 Web 端规范 (Nigeria Water Machine Leasing Platform)

## Why
尼日利亚水质安全与消费支付习惯带来强需求场景,需要 Web 官网作为核心线上转化阵地,以「水机分期租赁 + 全托管服务」模式降低首付门槛,并通过规范化的电子协议 + 渐进式催收体系控制坏账风险,同步输出 BV 值以支撑未来商业积分/等级体系。

## What Changes
- 新建面向尼日利亚本地用户的 Web 官网(1440px 桌面端标准,响应式降级至移动端)。
- 搭建「产品列表」与「租赁商城」双业务区,租赁商城为转化漏斗核心。
- 新建「我的账户」与「付款计划面板」,承载租后账单、提醒、催款、追款的渐进式状态体验。
- 接入多语言(EN/HA/YO/IG/中文)切换与本地支付网关唤起。
- 输出视觉/栅格/状态色彩规范,统一品牌绿 #00875A 与账单状态色。

## Impact
- Affected specs: 头部导航、首页 Hero、产品列表、租赁商城(列表 + 详情)、下单与支付、电子协议、付款计划、催款/追款通知、我的账户、多语言、响应式与弱网容错。
- Affected code(规划落点): 单页应用(SPA)路由分层,关键页面 `home / products / mall / mall-detail / checkout / agreement / account / billing / dunning / about`;全局 `i18n / theme / grid / status-color / auth / payment-gateway` 等基础模块。

## ADDED Requirements

### Requirement: Header 头部导航
系统 SHALL 在所有页面顶部提供统一 Header,包含品牌 Logo、核心导航(首页 / 产品列表 / 租赁商城 / 服务保障 / 关于我们 / 我的账户)、多语言切换(EN/HA/YO/IG/中文)、登录/注册入口、WhatsApp 在线咨询轻量图标。

#### Scenario: 桌面端导航
- **WHEN** 视口宽度 ≥ 1200px
- **THEN** 顶部水平排布,Logo 居左,导航居中,多语言与登录注册居右,视觉主色采用 #00875A。
- **AND** 鼠标悬停导航项显示 2px 下划线动画,激活态使用实色下划线 + 字重加粗。

#### Scenario: 移动端导航
- **WHEN** 视口宽度 < 1200px
- **THEN** 折叠为汉堡按钮 + 抽屉式菜单,Logo 与多语言切换器保留在顶栏,WhatsApp 图标悬浮于右下角。

### Requirement: 多语言切换
系统 SHALL 提供 EN/HA/YO/IG/中文五种语言,默认英语,切换时持久化至 localStorage,关键价格、CTA、状态文案需全部本地化。

#### Scenario: 切换语言
- **WHEN** 用户点击语言下拉并选择新语言
- **THEN** 当前页面文案立即切换,价格、BV 值、CTA 按钮同步刷新;选择持久化保留到下次访问。

### Requirement: 首页 Hero 区域
系统 SHALL 在首屏展示尼日利亚本地家庭/企业真实用水场景图,叠加核心价值主张(分期租赁 | 全托管 | 24H 水质保障),并放置醒目主 CTA「立即租赁」直达租赁商城。

#### Scenario: 首屏展示
- **WHEN** 用户访问首页
- **THEN** 首屏 100vh 内完整展示主视觉、价值主张三段式标签与主 CTA;主 CTA 使用品牌绿 + 高对比白字,具备 hover 抬升与阴影过渡。

### Requirement: 产品列表(Product List)
系统 SHALL 提供全量产品库展示,可能包含售卖与租赁产品,注重产品参数(规格 / 容量 / 日处理水量)与品牌统一视觉。

#### Scenario: 浏览产品
- **WHEN** 用户进入产品列表
- **THEN** 默认以网格 3 列卡片展示,支持筛选(类型/价格区间/规格)与排序;卡片包含主图、名称、关键参数摘要、查看详情按钮。

### Requirement: 租赁商城(Leasing Mall)列表
系统 SHALL 专供租赁业务转化,以头期款、BV 值、租期为视觉重点。

#### Scenario: 浏览可租产品
- **WHEN** 用户进入租赁商城
- **THEN** 卡片必须明显展示「头期款 ₦XXX」与「BV 数值」,租期以 chip 形式呈现,默认选中推荐租期。

### Requirement: 租赁详情页动态算价
系统 SHALL 在详情页支持租期切换并实时联动计算总租金、头期款、每月还款额、BV 值;固定底栏/侧边栏展示关键价格与「立即下单」按钮。

#### Scenario: 切换租期
- **WHEN** 用户点击 6/12/18/24 个月等租期
- **THEN** 价格区在 200ms 内刷新四项关键数字,「立即下单」按钮价格随之更新;切换过程保持输入态稳定,无重排抖动。

#### Scenario: 立即下单
- **WHEN** 用户点击固定底栏「立即下单」
- **THEN** 跳转至结算页并预填已选产品与租期。

### Requirement: 通知确认与电子协议
系统 SHALL 在下单环节强制要求用户确认接收账单和催款通知的手机号/邮箱,并勾选同意《账单与催收联络协议》;支付成功后必须在线签署《电子租赁设备协议》(明确逾期停机、追款等违约责任),生成具备法律效力的 PDF。

#### Scenario: 签署协议
- **WHEN** 用户完成头期支付
- **THEN** 进入电子协议页,必须滚动到底部并勾选「我已阅读并同意」方可签署;签署后生成 PDF 并提供下载链接。

### Requirement: 付款计划面板(Payment Plan)
系统 SHALL 在「我的账户」中可视化展示整个租赁周期:期数、每期金额、还款日、当前状态(待还/已还/逾期)。

#### Scenario: 查看付款计划
- **WHEN** 用户进入「我的账户 → 付款计划」
- **THEN** 顶部显示汇总(总期数、已还 X 期、待还 Y 期、累计 BV),下方以时间轴/表格展示每期明细,逾期项以警示橙 #DD6B20 标出。

### Requirement: 多级催款状态展示
系统 SHALL 在「我的账户」按逾期时长自动切换视觉强度:
- 账单提醒(到期前 3 天/1 天):温和待办,使用辅助蓝 #3182CE 或辅助黄 #D69E2E。
- 催款通知(逾期 1-7 天):橙色警示横幅 #DD6B20,文案「您的账单已逾期,为避免影响设备使用,请立即支付」。
- 追款通知(逾期 7 天以上):红色高危横幅 #E53E3E,限制非必要功能,文案升级为警告并提示可能触发设备锁定或违约金。

#### Scenario: 逾期升级
- **WHEN** 用户的某期账单从「待还」变为「逾期 1-7 天」
- **THEN** 「我的账户」顶部出现橙色横幅 + 强提示音/震动,快捷支付入口常驻。
- **AND WHEN** 逾期超过 7 天
- **THEN** 横幅升级为红色,「服务保障」「关于」等非必要 Tab 进入受限态(灰显并提示「为优先处理逾期,部分功能已限制」)。

### Requirement: 核心业务全链路状态
系统 SHALL 严格按照以下顺序流转并在 UI 各节点给出明确状态:选择产品 → 头期首付 → 电子协议 → 发货(即将上门安装) → 常规付款 → 催款/追款通知。

#### Scenario: 订单状态推进
- **WHEN** 用户完成任一节点
- **THEN** 订单详情页时间轴节点高亮当前态,同步发送短信与邮件通知,并在「我的账户」订单列表中反映最新状态。

### Requirement: 视觉与栅格规范
系统 SHALL 在 1920px 屏幕下采用 1440px 居中容器(左右 margin: auto),使用 12 列网格(单列 98px,列间距 24px);垂直间距遵循 96px(大模块) / 64px(常规区块) / 32px(标题与内容);状态色彩遵循品牌绿 #00875A + 警示橙 #DD6B20 + 危险红 #E53E3E + 辅助蓝/黄。

#### Scenario: 布局一致性
- **WHEN** 设计师/前端在任意 1440px 标准页面上排布
- **THEN** 元素落点均能落在 12 列网格内,垂直间距符合 96/64/32 体系,色彩使用状态语义而非装饰用途。

### Requirement: 响应式与弱网容错
系统 SHALL 在 1200px-1440px 视口区间使用相对比例自适应,小于 1200px 平滑降级至移动端布局;所有支付与协议提交按钮必须配置 Loading + Disabled 锁定,防止重复扣款;账单及催款页面在初次加载后对关键数据(待付金额、还款账号)做本地缓存,断网时仍可查看。

#### Scenario: 弱网提交
- **WHEN** 用户在弱网下点击「立即支付」/「确认签署」
- **THEN** 按钮立即进入 Loading 态并禁用,文案改为「处理中…」;若 30s 内未响应,提示「网络不稳,正在重试」并保留最后一次提交状态。

#### Scenario: 断网查看账单
- **WHEN** 用户处于断网状态再次打开账单页
- **THEN** 页面渲染本地缓存的待付金额、还款账号与最近一期状态,顶部显示「离线模式」指示条。

### Requirement: 支付链路唤起
系统 SHALL 在移动端确保支付和催款链接能拉起本地常用支付钱包或银行转账界面;桌面端优先跳转网关网页版。

#### Scenario: 移动端唤起
- **WHEN** 用户在移动端点击支付链接
- **THEN** 优先尝试唤起本地支付 App(通过 universal link / intent),唤起失败则降级为 H5 收银台。
