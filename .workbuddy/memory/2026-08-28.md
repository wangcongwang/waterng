## Sponsor Network 折叠失效真正根因（2026-08-28 续）

用户再次反馈还是折叠不起来。此前我误判为"默认全展开"，但真因不同：

真因：.sn-children 设了 display:flex，而 hidden 属性依赖浏览器默认 [hidden]{display:none}。任何显式 display 都会压过 [hidden]，导致 hidden 属性完全失效、子节点永远显示。之前 jsdom 测试只检查 hidden DOM 属性是否随点击切换（能切换），没模拟真实 CSS 级联，所以"通过"了却没发现浏览器里 display:flex 让 hidden 形同虚设。测试对象错了。

修复：新增 CSS .sn-children[hidden]{display:none}（特异性高于 .sn-children），确保 hidden 生效。

教训：给带 hidden 切换的元素写 display 时，必须补 .x[hidden]{display:none}；jsdom 测显隐要断言 getComputedStyle().display 而非仅 hidden 属性。
