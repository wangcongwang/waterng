- **下单链路**：products → cart → checkout → shipping → order，account 旁挂。3 格步骤条（Confirm your order / Payment method / Shipping pickup）；5 种支付（cod / card / ussd / bank / balance）；订单号 `AQ-` + 6 位，字符集排除 I/O/0/1；存储 `al.orders`。
- **BV 归属**：1 BV / ₦1,000 向下取整；存在推荐人 + 推荐人≠自己 + BV>0 三条件成立时，BV 全额上浮给推荐人（写 `al.bvCredits`）。
- **会员注册**：一页 7 分区长表单，真实必填 8 项；Member ID = `NG`+8 位，注册页生成且只读，校验只在 login / account / 推荐参数三处；注册即登录，3 秒跳 account.html。
- **登录**：仅 Member ID + 密码，只校验格式与长度，不比对凭据；成功后按 `?next=` 回跳。
- **账户 4 Tab**：Overview / Orders / Profile / Sponsor Network。订单按 `memberId`（权益归属）与 `operatorId`（实际操作）分 My orders / Member orders。
- **奖金 KPI**：Member Bonus = 自购 BV(Σ al.orders.bv) + 推荐 BV(al.bvCredits)；Member Ecoin 走独立台账 al.ecoin。
- **九类奖金**：Elite / Pro Elite / Super Elite / Stockist / LeaderShip / Welcome / Car / Performance / Builder（+ Total）。**均为展示型字段，代码中无任何比例与晋升条件**。
- **资金闭环**：Recharge → Bonus；Bonus To Ecoin；Ecoin To Ecoin；Ecoin 可抵扣订单（结算页 balance 支付，当场扣款并置 Paid）。
- **五条业务线**：Welcome Pack / Repeat Purchase（DP 成交、RP 仅参考）/ Auto-Maintenance（**硬门槛 ≥90 BV，无自动扣款**）/ Upgrade（6 档 Bronze→Corporate）/ Team Inquiry。

## 工具经验（下次做 PPT 复用）

- **tencent-pptx 流程**：STORY.md → DESIGN.md → `slidep-start` 建 pptx 并常驻编译 → `present_files` 打开预览 → 逐页写 `pages/slide_NN_*.jsx` → `slidep-validate` 全量校验。
- **`slidep-validate` 会做溢出检查**，返回 `CONTENT_OVERFLOW` 并给出具体行号与溢出像素。本次 25 页中 3 页溢出（+13 / +2 / +53px），靠收 gap、减 padding、删冗余块修掉。写页时务必先算高度（A 100 + B 540 + C 40 = 680）。
- **slidep DSL 限制**：只支持 `display: flex`，**不支持 grid 和 calc()**；换行必须用 `<br />`；富文本只能用 `<span style>`。
- **踩坑：底图体积导致云端转换超时**。4 张 1536×1024 PNG 共 6.5MB → `slidep-export-images` 上传 docs.qq.com 转换返回 **HTTP 504**。用 `sips -s format jpeg -s formatOptions 82` 压到 935KB 后 pptx 从 6.7MB 降到 1.1MB。**生成大幅底图后应先压成 JPEG 再引用**，PNG 原图归档到 `resources/images/source/`。
- **ImageGen 产物右下角带「AI生成 WORKBUDDY」水印**，解法是在该角落叠一层 `linear-gradient(315deg, rgba(8,10,32,~1) 0%, transparent 64%)` 压掉，或在该位置放落款元素盖住。
