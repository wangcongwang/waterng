## 1. 画布与母版（A/B/C 三区）

- **画布**：1280 × 720 px（16:9）
- **页面 padding**：上下 20px、左右 60px
- **内容可用宽度**：1280 − 60×2 = **1160px**
- **内容可用高度**：720 − 20×2 = **680px**

| 母版区 | 垂直位置 | 高度 | 内容规则（本项目具体值） |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | y = 20–120 | 100px | 主标题 `34px bold`，颜色 `#202259`；标题下方 8px 处可挂 1 行 `16px` 灰色引导句；**禁止**在右侧放 200×70 装饰小图 |
| **B · 内容区** | y = 120–660 | **540px 可用** | 所有正文、卡片、图示、表格；上下留 20px 呼吸 |
| **C · 页脚条** | y = 660–700 | 40px | 左侧 L3 角标（小色块 + `14px` 灰字 `AQUALIFE · 前端系统功能讲解`）+ 右侧页码 `NN / 25`，`14px` `#5C646A` |

- 封面（P01）、章节过渡（P05/P14/P18）、结束页（P25）**省略 C 区**，采用自定义版式。
- 相邻内容页之间的 A 区标题 x 坐标、C 区页码 x 坐标**必须逐页一致**。

## 2. 颜色系统

> 取自产品实际设计令牌 `assets/css/elken-tokens.css`，保证 PPT 与产品界面同一视觉语言。

| 角色 | hex | 令牌来源 | 用途 |
| :--- | :--- | :--- | :--- |
| **主色 ink** | `#202259` | `--ek-blue` Deep Vital Blue | 标题、标题栏底、深色卡片、页脚角标 |
| **辅色 aqua** | `#2AA7CF` | `--ek-aqua` Aqua Energy Blue | 流程箭头、次强调、图标、数据副系列 |
| **强调色 pink** | `#F287B7` | `--ek-pink` Radiant Bloom Pink | 仅出现在焦点元素：巨型数字、关键规则标记、CTA |
| **中性 charcoal** | `#25292C` | `--ek-charcoal` | 正文文本 |
| 中性面（辅助） | `#FFFFFF` / `#F4F6F8` / `#E3E6E8` | `--ek-surface` / `--ek-surface-page` / `--ek-border` | 卡片面、页面底、分割线 |

### 2.1 色彩面积分配

| 色彩角色 | 面积占比（常规页） | Hero 页 |
| :--- | :--- | :--- |
| 主色 `#202259` | ≤ 35% | ≤ 55%（封面/章节页可到 90%） |
| 辅色 `#2AA7CF` | ≤ 25% | ≤ 25% |
| 强调色 `#F287B7` | **≤ 10%** | 15–20% |
| 中性色 | 剩余（≥ 35%） | 剩余 |

**色彩节奏**：P01/P05/P12/P14/P18/P20/P25 的深色占比显著高于其余页；P03/P06/P11/P19/P24 保持近白底、强调色 ≤ 5%。**禁止全篇色彩比例雷同**。

### 2.2 渐变与半透明策略

| 用法 | 具体值 | 使用位置 |
| :--- | :--- | :--- |
| 主渐变 | `linear-gradient(135deg, #202259 0%, #2AA7CF 100%)` | 卡片头部、章节页大字底纹、巨型数字底 |
| 浅蓝底 | `rgba(32,34,89,0.06)` | 表格表头、信息条、清单底 |
| 青色高亮 | `rgba(42,167,207,0.10)` | 结论框、公式条、关键行 |
| 粉色高亮 | `rgba(242,135,183,0.14)` | 注意/缺口标记、关键规则 |
| 图上蒙版 | `rgba(15,16,52,0.55)` | 封面与章节页压暗底图，保证白字可读 |
| 卡片浮起 | `boxShadow: '0 4px 20px rgba(13,20,23,0.08)'` | 所有白色卡片 |
| 背景装饰 | `opacity: 0.15–0.3` | 底层大色块、装饰圆 |

**禁忌**：单页出现 ≥2 套主色板；高饱和撞色铺满 ≥1/3 页面。

## 3. 字体系统

**本项目仅使用 2 套字体家族**（合规上限）：

| 家族 | 字体栈 | 用途 |
| :--- | :--- | :--- |
| **A · 主字体（商务现代）** | `Inter, PingFang SC, Helvetica Neue, sans-serif` | 标题、正文、表格 —— 西文 Inter，中文 PingFang SC |
| **B · 等宽字体** | `Menlo, ui-monospace, monospace` | 仅用于 ID、`localStorage` 键名、订单号、字段名等技术字面量 |

### 3.1 字号层级表

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | **68px** | bold | 1.15 | −1.5px | 仅 P01 |
| 章节大字 | **64px** | bold | 1.1 | −1px | P05 / P14 / P18 |
| **巨型锚点数字** | **88–96px** | bold | 1.0 | −2px | P12 / P16 / P20 / P25（每页 1 个） |
| 页面主标题 | **34px** | bold | 1.3 | 0 | 每页 A 区固定 |
| 卡片小标题 | **23px** | bold | 1.35 | 0 | 卡片头 |
| 正文（叙事型） | **22px** | normal | 1.55 | 0 | 段落说明 |
| 正文（数据密集） | **20px** | normal | 1.5 | 0 | 清单、字段说明 —— 本项目主流密度 |
| 表格 / 辅助 | **17px** | normal | 1.4 | 0 | 表格单元格、副标注 |
| 等宽技术字面量 | **17px** | normal | 1.4 | 0 | 家族 B |
| 脚注 / 页码 | **14px** | normal | 1.4 | 0.3px | C 区 |

> 说明：本项目为**数据密集型功能讲解**，字段与界面对照内容多，故正文基准取 20px；仅纯叙事段落用 22px。巨型数字用家族 A 的 `bold` 并与正文形成 ≥4 倍字号跳跃。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 图数 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 P01 | 主标题 + 副标 + 主视觉 | 40 | 1 | ≥ 60%（全幅底图） |
| 目录 P02 | 3 章节条目 + 引导句 | 150 | 0–1 | — |
| 章节过渡 P05/P14/P18 | 章节大字 + 一句小标 | 28 | 1 | ≥ 60% |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | **200** | 1 | ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + N 卡 | **每卡 ≥ 100** | 0–N | — |
| 数据页 P21 | 标题 + 表 + 洞察 | 200 | 1 | ≥ 40% |
| 结束页 P25 | 三句收束 + 落款 | 40 | 0 | — |

- **常规内容页留白 ≤ 30%**（本项目内容量大，收紧自上而下限 35%）。
- **容器填充率 ≥ 85%**：卡片内文字垂直占用 ≥ 卡片高度 85%；高度 ≥ 380px 的卡片正文 ≥ 100 字。
- **底栏锚定**：卡片尾部元素（要点条 / 徽标行）用 `marginTop: 'auto'` 或父容器 `justifyContent: 'space-between'` 钉底。
- **横向兄弟卡对齐**：同一行卡片的三段（标题 / 正文 / 尾部）y 轴等高，尾部元素 y 差 ≤ 16px。
